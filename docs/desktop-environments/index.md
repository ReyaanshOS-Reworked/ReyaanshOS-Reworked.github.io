# Desktop Environments

Explore desktop environments and interfaces for different form factors.

## KDE Plasma

KDE Plasma is a customizable desktop environment with a traditional desktop layout, application launcher, panel, and system settings.

[Official KDE Plasma website](https://kde.org/plasma-desktop/)

## KDE Plasma Mobile

KDE Plasma Mobile is a touch-oriented interface designed for mobile Linux devices.

[Official KDE Plasma Mobile website](https://plasma-mobile.org/)
